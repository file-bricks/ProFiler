ProFiler Suite - Third-Party and Release Inventory
Last reviewed: 2026-07-22

Scope
=====

This inventory is derived from pyproject.toml, requirements.txt,
requirements-lock.txt and requirements-build.txt. It is not a dump of the
maintainer's global Python environment. The exact Python distribution set used
for a concrete EXE is recorded in BUILD-PROVENANCE.json by build_exe.bat.

to distribution and Store review; replacing the project license statement does
not replace PyMuPDF's own terms. Preserve license notices for all bundled
transitive dependencies.

Build-only dependency
=====================

PyInstaller 6.21.0 - GPL-2.0-or-later with the PyInstaller bootloader exception.
It is pinned in requirements-build.txt and is not an application feature.

External native tools
=====================

Tesseract OCR - Apache-2.0. Required for OCR at runtime.
Poppler utilities - commonly GPL-2.0-or-later; verify the exact Windows
distribution and its notices before bundling.

Neither Tesseract nor Poppler is currently bundled by the canonical
build_exe.bat. OCR/PDF-to-image Store claims therefore remain blocked until the
actual package contains the selected binaries, their notices and a real
installed-package smoke test.

Release checklist
=================

1. Build only from a clean, pushed commit using requirements-build.txt.
2. Keep BUILD-PROVENANCE.json and SHA256SUMS.txt next to the artifact.
3. Review the artifact-specific python_packages list in the provenance file.
4. Add notices for any selected Tesseract/Poppler distribution.
5. Record Authenticode status, MSIX identity, WACK result and Store readback.
6. Do not call a local unsigned EXE a Store-ready package.
