EXTERNAL PROGRAMS AND CURRENT BUILD BOUNDARY
The source checkout does not contain Tesseract or Poppler binaries. build_exe.bat
requires these paths before it can package an executable:
  runtime/tesseract/tesseract.exe
  runtime/tesseract/tessdata/
  runtime/poppler/pdftoppm.exe
  runtime/poppler/pdfinfo.exe
These paths are absent from the reviewed checkout. The native executable build
is therefore blocked. Source workflows can call host-installed OCR/PDF tools.
This file does not establish a Store package, WACK result, or bundled-license
review.
